## Описание работы программного кода
🟦=>🟩=>🟨=>🟪=>⬜
    
    🟦main: 
        -читает аргументы запуска (flag = {mode, host, port, username})
        -если mode == "server", запускает функцию runServer
        -если mode == "client", запускает функцию runClient


    🟩runServer (host,port):
        -определяет строку адреса из host и port
        -начинает сервер (listener), который слушает на определенном адресе через протокол TCP
        -начинает goroutine, который запукскает цикл для приема соединений  (listener.Accept()). Для каждого соединения начинает новый goroutine handleConnection для работы с этим соединением
        -добавить defer для завершения сервера
        -эта функция стоит не завершается до того, как получит сингал на канале closeServerChan 

    🟨handleConnection(conn):
        -читает из соединения данные ник (username)
        -cохраняет соединения его адресом (ключевым словом - conn.RemoteAddr) 
        -сообщает всем клиентам о новым соединении (Broadcast)
        -начинает цикл, чтобы слушать все сообщения от этого соединения. При сообщении передает сообщене в новый goroutine handleMessage
        -добавить defer для завершения соединения

    🟪handleMessage(sender, message):
        -проверяет тип сообщения (private/broadcast) тем, что начинается ли сообщение с символом "@"
        -для private сообщение, запускает функцию sendMessageToClient(private=true)
        -для broadcast сообщение, запускает функцию broadcastMessage

    ⬜broadcastMessage:
        -отправляет всем клиетам, кроме отправителя, сообщение через функцию sendMessageToClient(private=false)

    ⬜sendMessageToClient(sender,message,recipent, private=bool)
        -Ишет получателя из MAP клиентов и отправляет сообщение. Если аргумент private = true, то отмечает сообщение отметкой [PRIVATE]
            
    🟩runClient(host, port, username)
        -определяет строку адреса из host и port
        -начинает соединение (net.Dial) к определенному адресу через протокол TCP
        -начинает gorountine receiveMessages, чтобы слушать все поступающие сообщения
        -запускает функцию sendMessage, чтобы читает сообщние у клиента на консоле, и его отправляет на сервер
